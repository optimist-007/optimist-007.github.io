# Simran Revankar — personal website

This repository powers the public website at https://optimist-007.github.io.

## Edit the website

1. Open https://app.pagescms.org and sign in with the GitHub account that owns this repository.
2. Select the `optimist-007.github.io` repository.
3. Choose **Profile and site settings**, **Blog posts**, **Gallery**, or **Videos**.
4. Edit the content and save. Pages CMS commits the change to GitHub.
5. GitHub Pages republishes the site automatically. Allow a few minutes for changes to appear.

Only GitHub accounts authorized for this repository can save changes.

## Files

- `index.html` renders the public website.
- `content/site.json` stores profile, theme, services, CV, and social links.
- `content/blogs.json` stores blog posts.
- `content/gallery.json` stores photographs and captions.
- `content/videos.json` stores video links.
- `.pages.yml` configures the Pages CMS editing interface.
- `media/` stores uploaded images and documents.
